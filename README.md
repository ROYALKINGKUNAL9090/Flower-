# 🌹 Flower & Love Wish Animation

A beautiful Python Turtle & HTML5 Canvas animation project that draws a rose made of words ("My Love") layer by layer, complete with stem, leaves, and starry background.

---

## 📸 Preview

The program generates a colorful flower crafted from custom text:
- **Center to Outer Layer:** Pink and crimson petals drawn point-by-point.
- **Stem & Leaves:** Green curved stem with leaf petals.
- **Background:** Decorative star symbols and footer message.
